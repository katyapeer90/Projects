# Katya Peer — DevOps Portfolio

A minimal portfolio site built with React, TypeScript, Vite and Tailwind CSS.

## Run with Docker Compose

```bash
docker compose up --build
```

Open `http://localhost:8080`.

Stop it with:

```bash
docker compose down
```

## Run locally with Node

```bash
npm install
npm run dev
```

Vite will print the local development URL.

## Production build

```bash
npm run build
```

The production site is generated under `dist/`.
